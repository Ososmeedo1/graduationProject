# Project Tools Documentation

This document provides an overview of the tools and technologies used in this project, categorized by their purpose.

| **Category**              | **Tools**                              |
|---------------------------|----------------------------------------|
| **Framework**             | React                                  |
| **UI Layout**             | HTML5                                  |
| **Styling**               | CSS3, Tailwind CSS                     |
| **Component Architecture**| React Components                       |
| **State Management**      | React Hooks                            |
| **Routing**               | React Router DOM                       |
| **Data Visualization**    | Chart Library (e.g., Recharts)         |
| **API Communication**     | Axios                                  |
| **Authentication UI**     | Formik                                 |
| **Validation**            | Yup                                    |
| **Icons**                 | Icon Library (e.g., Lucide)            |
| **Build Tool**            | Vite                                   |
| **Deployment**            | Netlify                                |
## Additional Tools and Libraries

- **i18n.js**: For internationalization and localization.
- **PostCSS**: For processing CSS with plugins.
- **ESLint**: For linting and maintaining code quality.
- **Prettier**: For code formatting.
- **React Context API**: For managing global state.
- **Custom Hooks**: For reusable logic (e.g., `useAlert`, `useAuth`, `useDebounce`, etc.).
- **Utility Functions**: For error handling, formatting, storage, and validation.

## Folder Structure Overview

The project is organized into the following main folders:

- **src/components**: Contains reusable React components categorized by feature.
- **src/pages**: Contains page-level components for different sections of the application.
- **src/services**: Includes API services and i18n setup.
- **src/styles**: Contains global CSS and variable definitions.
- **src/types**: Defines TypeScript types for various entities.
- **src/utils**: Contains utility functions for common operations.

For more details, refer to the respective files and folders in the project structure.
